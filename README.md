# 非技术岗求职雷达 · 中国科技公司

面向实习生和应届生的公开岗位清单，聚焦中国科技公司的产品、运营、市场、战略、商务、项目管理、设计和职能岗位。

岗位直接来自企业官方招聘网站。目前接入 **字节跳动招聘** 与 **腾讯校招**；不抓取 BOSS 直聘、猎聘等二手平台，不改写 JD，不做匹配分，也不自动投递。

> [打开可筛选的岗位入口](./docs/) · [下载 JSON](./data/jobs.json) · [下载 CSV](./data/jobs.csv)

## 怎么用

1. 打开上面的筛选入口，按关键词、职能、实习/校招、城市和公司过滤。
2. 点击“去官网申请”，回到企业官方页面确认岗位要求并投递。
3. GitHub Action 每天北京时间 08:20 自动刷新；`first_seen_at` 表示本项目首次发现时间。

线上运行链路是：GitHub Actions 云端抓取 → 提交 JSON/CSV 到 GitHub → 在同一次任务中部署 GitHub Pages。本地电脑不参与定时任务，也不是生产数据存储。

## 收录范围

- 产品、产品策划、产品运营
- 内容/用户/商业/游戏运营
- 市场、增长、品牌、公关
- 战略、商业分析、投资
- 销售、商务拓展、客户成功
- 项目/项目群管理
- 交互、视觉、用户研究、游戏美术
- 人力、财务、法务、行政等职能

第一版只覆盖实习和校招。分类是基于官方职位类别和岗位标题进行的机械归类；岗位正文、要求和申请链接保持官方原貌。
