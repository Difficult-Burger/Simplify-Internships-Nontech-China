## 贡献岗位

发现漏岗、错分或失效链接，可以通过 [GitHub Issues](https://github.com/Difficult-Burger/Simplify-Internships-Nontech-China/issues) 反馈。申请链接必须来自企业官方招聘网站。

## 本地运行

需要 Python 3.12，无第三方运行时依赖。

```bash
python main.py fetch
python main.py validate
python -m http.server 8000
```

访问 `http://localhost:8000/docs/` 即可预览筛选页面。
